# UberSkills

Save, share and discover trusted agent skills.

## Install

```bash
npx skills add uberskills/uberskills -g -y
```

## Update

```bash
npx skills update
```

## What it does

Gives you a personal list of trusted agent skills at `~/.config/uberskills/skills.json`.

On first use, it scans your already-installed skills and pre-fills the list as a starting point. From there you can add, remove, and view skills conversationally.

```
"What skills do I have saved?"
"Save this skill: github:owner/repo"
"Remove brave-search from my list"
```
